Le trajet d'un message dans ton chatbot

Chaque fois que tu écris, ton message fait le tour de cette ligne. Claude ne retient rien : c'est ton programme qui lui renvoie toute la conversation à chaque passage.

Les quatre lignes

Bleue : l'aller

Ton message est ajouté à l'historique, puis tout l'historique part chez Claude.

historique.append({"role": "user", ...})

Verte : la clé

Elle vient de Windows et prouve à Anthropic que c'est ton compte qui paie. Elle n'est écrite dans aucun fichier.

ANTHROPIC_API_KEY

Ambre : les outils

Si Claude a besoin de l'heure ou d'un calcul exact, il fait un détour : ton code Python répond, puis il reprend.

stop_reason == "tool_use"

Rouge : le retour

La réponse s'affiche pendant qu'elle s'écrit, puis elle rejoint l'historique et le fichier de sauvegarde.

st.write_stream(...)

Pourquoi Claude « se souvient »

À chaque tour, on lui renvoie toute la liste. Elle grandit de deux messages : ta question, puis sa réponse.

Tour 1
toi ₁
Tour 2
toi ₁claude ₁toi ₂
Tour 3
toi ₁claude ₁toi ₂claude ₂toi ₃

Entouré en jaune : le nouveau message de ce tour.

Le détour par les outils

Une petite boucle while True dans repondre().

  1. Claude répondavec le texte, ou une demande d'outil
  2. Il demande un outil ?non : c'est la réponse finale, on sort de la boucle
  3. Ton code exécute la fonctionexecuter_outil("calculer", {...})
  4. On renvoie le résultat à Claudeun message « tool_result », puis on revient en haut
